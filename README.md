# 🕵️ AI Data Detective

AI-powered data quality, anomaly detection, visualization, and intelligent data analysis application built with Python and Streamlit.

## 🚀 Live Demo

https://ai-data-detective-vpp9kgwv57dpwfbwxzard.streamlit.app

## 📌 Features

- CSV and Excel dataset upload
- Data quality analysis
- Missing-value detection and cleaning
- Duplicate detection
- IQR anomaly detection
- Isolation Forest machine learning
- Interactive Plotly visualizations
- Smart data insights
- Interactive row investigation
- Anomaly investigation
- Local AI chatbot using Ollama and Qwen 2.5 3B
- Professional PDF reports
- Dataset health score
- Downloadable results

## 🛠️ Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
- OpenPyXL
- Ollama
- Qwen 2.5 3B
- ReportLab

## 🏗️ Architecture

User → Streamlit → File Upload → Data Analysis → Anomaly Detection → Visualization → AI Analysis → Reports

## 🎯 Objective

AI Data Detective combines data analysis, machine learning, visualization, and AI-assisted investigation into a single application to help users understand and identify issues in their datasets.

## 🌐 Deployment

Deployed using Streamlit Community Cloud and connected to GitHub.
